This directory contains the PWA app icons in various sizes.

## Shortcut Icons

- shortcut-search-96x96.png
- shortcut-sessions-96x96.png
- shortcut-qr-96x96.png

## Design Guidelines

- Use the platform brand colors (#3B82F6 primary)
- Include a recognizable parking symbol (P or car icon)
- Ensure icons are readable at small sizes
- Follow PWA maskable icon guidelines for adaptive icons

## Generation

Icons can be generated from a single high-resolution source using tools like:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator
- Adobe Illustrator/Photoshop batch export
